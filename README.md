# ChopinEtudes  
Experimental music player for Chopin's piano etudes...  

## Quick Info
This is an experimental music player for Chopin's piano etudes, to explore iframe embedding through HTML and JavaScript. All assets are from Wikimedia Commons; we are not affiliated or endorsed by Wikimedia Commons. Test out ChopinEtudes [here](https://kpoovakan.github.io/chopinetudes).
